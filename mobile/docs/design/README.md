# Tally: protótipo mobile (Claude Design)

Arquivos exportados do canvas "Tally — protótipo mobile" (Claude Design, 2026-11-16).

| Arquivo | Conteúdo |
|---|---|
| `Main.dc.html` | Telas do app (tema claro, casal). Contém todo o fluxo e os estilos. |
| `Dark.dc.html` | Mesmo app no tema escuro. Importa o `Main`. |
| `Family.dc.html` | Mesmo app para uma família de 4. Importa o `Main`. |
| `Components.dc.html` | Guia de componentes. |
| `canvas.json` | Índice do canvas (posição e tamanho dos artboards). |

Observações:
- São referência visual, não código Flutter. Fontes: Space Grotesk (títulos) e Inter.
- Os `.dc.html` precisam do runtime do Claude Design (`support.js`, não incluído), então não abrem direto no navegador.
- A logo (quatro barras com um risco diagonal) é a mesma de `assets/icon/tally-icon.svg`.
